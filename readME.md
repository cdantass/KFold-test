# Projetos de Machine Learning

Este repositório reúne atividades e implementações de diferentes algoritmos de Machine Learning. Cada projeto está organizado em sua própria pasta e possui um README específico com a explicação do algoritmo, preparação dos dados, forma de execução e resultados obtidos.

## Projetos

- **K-Fold e GroupKFold:** comparação entre métodos de validação cruzada.
- **Support Vector Machine:** classificação utilizando o algoritmo SVM.
- **Random Forest:** classificação baseada em um conjunto de árvores de decisão.
- **Clusterização:** identificação de grupos e padrões sem a utilização de classes previamente definidas.
- **Previsão de séries:** análise de dados organizados ao longo do tempo.
- **Apriori:** identificação de itens frequentes e criação de regras de associação.
